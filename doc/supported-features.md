| Tier | Meaning |

| partial | Works within limits — parsed and matched, but a constraint applies (see the note). |

Tier and Note describe PiCC behavior. **Claude evidence** describes only the upstream Claude Code surface: documented = stated by an allowlisted official page; observed = reproduced on the named Claude version and bounded path; inferred = reasoned from indirect evidence; unverified = the reviewed evidence does not establish the behavior. Multiple qualities on one row are intentionally mixed; a blank cell means the entry was not part of this audit.

**Related references** are navigation and context only; search this document or the registry by ID. They do not imply a shared tier, evidence quality, or dependency. A separate ⚠ marker means PiCC fails to enforce an upstream restriction or mandatory gate, allowing an operation that should be restricted to run freely; `/doctor` labels detected project-specific safety findings.
