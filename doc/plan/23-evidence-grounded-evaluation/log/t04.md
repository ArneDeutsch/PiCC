## Decisions / friction

- **CRLF handling.** All three .md files are CRLF (confirmed via `od -c`; no `.gitattributes`
  rule for `*.md`). Kept the two reference-file edits to single physical lines (both files
  keep the edited spans on one line — ticket-integration is one giant line), so no newline
  bytes were introduced and EOL stayed CRLF. The CHANGELOG block insert was done via a Python
  binary splice writing `\r\n` explicitly, to avoid mixing LF into a CRLF file.
- **Test markers vs. bold.** `collapse` only lowercases + collapses whitespace; it does NOT
  strip `**`. So markers were shaped to sit *inside* a bold run (`**investigates the project
  and rates whether the scope looks valuable**`) or entirely outside bold (`coordinator adds
  no new`), never straddling a `**` boundary.
- **Dash seam / forward slashes (standing rule).** The `1–2` density marker is built from
  `String.fromCodePoint(0x2013)`; tool/path markers assert forward-slash forms
  (`` `read`/`grep`/`glob` ``, `repo-root-relative forward-slash path`).
- Did NOT touch either `SKILL.md`, `evaluation-engine.md`, or the evaluate mode files (read
  the engine contract but only referenced it). Appended a new `describe` block rather than
  editing the existing `proposal-gate wiring floor markers (evaluate-skill t04)` block, so
  every previously-pinned substring in both describe blocks is preserved.
