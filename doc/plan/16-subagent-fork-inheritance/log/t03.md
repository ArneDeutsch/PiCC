## Decisions

- **Registry id / tier:** `tool.Agent.fork` (two-dot free-form id, per spec), tier
  **`partial`**. Placed immediately after `tool.Task` in `TOOL_ENTRIES`.
- **Note wording:** single line, split into a VERIFIED clause and a
  "PiCC-DEFINED / INFERRED limits" clause (house style). It states, from the SHIPPED
  code in `src/runtime/subagents.ts`: inherits parent conversation (full history) +
  parent model + parent tools via `SessionManager.forkFrom` into a brand-new persisted
  child transcript; output isolation kept; MAIN-SESSION dispatch only (nested
  `depth ≠ 1` visible-degrades); system prompt is a same-context RECONSTRUCTION (not
  byte-identical → forgoes the prompt-cache saving); `CLAUDE_CODE_FORK_SUBAGENT` gate
  (=1 on / present-but-off degrades / unset ⇒ ENABLED, a DIRECTIONAL PiCC parity
  divergence); model overridden by `CLAUDE_CODE_SUBAGENT_MODEL` env AND a per-call
  `model` arg; NON-RESUMABLE; a fork cannot spawn another fork (visible refusal —
  INFERRED mechanism, runtime-set dispatcher marker); print/headless/no-session degrade;
  `run_in_background` removal NOT adopted; `isolation:"worktree"` not honored; version
  gate (v2.1.117+) not mirrored; `name` doesn't affect inheritance and PiCC does NOT
  reproduce anthropics/claude-code#76019. Ends with `See research §2.9 (§4.3)`.
- **Research §:** used **§2.9 "Fork the current conversation"** (2.8 was last), so the
  registry `(§2.9)` reference resolves. Added the §2.6 back-pointer
  `(except a fork — see §2.9)`.
- **Cross-references:** added a fork clause to `tool.Agent`, `tool.Task`, and
  `feature.background-agents`; reworded `tool.SendMessage` from "fork/agentOverride
  dispatches … are unsupported" to "fork dispatches are non-resumable (… see

- Env gate: `gateOff = gateRaw !== undefined && !isEnvTruthy(gateRaw)`; unset ⇒ enabled.

  degrades — reflected as "present-but-off").
- Main-session predicate: exact `opts.depth === 1` (degrade is the complement
  `opts.depth !== 1`), not `> 1`. Reflected in registry + research + architecture.
- Model resolution order (subagents.ts ~1306): `CLAUDE_CODE_SUBAGENT_MODEL` env beats
  per-call `model` arg beats frontmatter `model:` beats session model. Both env and
  per-call overrides disclosed so "same model as parent" stays truthful.
- Fork-spawns-fork: enforced via the runtime-set `dispatcherIsFork` marker (t02), NOT a
  tool parameter and NOT depth — documented as INFERRED mechanism.
- `forkFrom` seeds a brand-new persisted child file, forced non-resumable; SendMessage
  refuses it.
