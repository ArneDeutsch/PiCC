# t01 execution log — scratchpad primitive

- Added pure `toNativeSafeTempForm(p, platform = process.platform)` to `src/util/env.ts`
  (already the subprocess-env module — no new cross-layer edge). win32 ⇒
  `p.replace(/\\/g, "/")`; all other platforms ⇒ input unchanged. `shell` deliberately not a
  param per spec. Doc comment explains the MSYS-vs-native namespace mismatch and why the
  forward-slash drive-letter form is agreed by Git Bash / PowerShell / native Node.
- `src/index.ts`: added `import os from "node:os"` (fs/path already present); imported
  `toNativeSafeTempForm` from `./util/env.js`.
- Created the per-session scratch dir EAGERLY in the outer `activate` scope, placed
  immediately before the `void (async () => {…})()` cwd-override IIFE and well before the
  `before_agent_start` registration — so the literal path is captured synchronously at the
  t02 injection call site, not raced/left-undefined by the error-swallowing async closure.
- Creation order per spec (load-bearing): root = `CLAUDE_CODE_TMPDIR || os.tmpdir()` →
  `fs.mkdtempSync(path.join(root, "picc-scratch-"))` → `fs.realpathSync` → `toNativeSafeTempForm`.
  Held in `let scratchDir: string | undefined` for t02.
- Decisions on "Left open":
  - Did NOT add a flattened-project prefix to the mkdtemp template (cosmetic; kept the plain
    `picc-scratch-` template for simplicity).
  - Did NOT add any process-exit cleanup / chmod (out of scope; retention is #41). No 0700
    assumption made.
- Wrapped creation in try/catch → on failure logs to stderr and leaves `scratchDir`
  undefined rather than crashing activation (completeness floor, matching surrounding
  console.error idiom). t02 will simply omit guidance when undefined. This is a small
  robustness addition not explicitly in the spec but consistent with index.ts conventions.
- No env var introduced; no spawnHook change. The earlier `CLAUDE_SCRATCHPAD_DIR` export is
  absent, as required.
- Tests: extended `test/subprocess-env.test.ts` with a table-driven, platform-injected
  `toNativeSafeTempForm` block (ungated, all OSes). Locks the #48 regression: win32 result
  matches `/^[A-Za-z]:\//`, never leading-slash, never bare `/tmp/...`; linux/darwin
  unchanged; idempotence on win32; default-platform delegation.
- Verification: `npm run typecheck` clean. `npm test` → 1243 passed / 16 skipped (baseline
  1237/16; +6 are the new toNativeSafeTempForm cases). No new failures.
- Surprising: tsconfig has no `noUnusedLocals`, so the held-but-not-yet-consumed `scratchDir`
  does not trip typecheck — t02 can consume it without any placeholder use here.
