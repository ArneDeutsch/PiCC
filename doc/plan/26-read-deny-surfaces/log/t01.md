## Directory-argument edge — OBSERVED result (item 4)
Ran it rather than assumed. Under `deny: Read(secrets/**)`:
- `Glob {path:"secrets"}` and `Grep {path:"secrets"}` → **`deny`** (BLOCKED). `matchesRule("Read(secrets/**)", Glob{path:"secrets"})` is **`true`** in BOTH directions — the glob engine treats `secrets/**` as covering the bare directory node too. So the bare-directory case is NOT a gap; naming the directory to enumerate it is caught.
- The REAL residual gap (basis for the t02 honesty caveat) is a read call with **no path** or `path:"."`: `Grep {}` and `Grep {path:"."}` → `default`. Nothing for the path matcher to test, so the scoped rule cannot fire; matching files stay reachable via results. Only a bare `deny: Read` forecloses that (matches feature.md's stated limit). Pinned all of these in the test.
